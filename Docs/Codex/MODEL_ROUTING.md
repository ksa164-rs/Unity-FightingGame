# 再利用できる役割・モデル選択ルール

役割（何を担当するか）とモデル（どの深さ・コストで解くか）を別々に選ぶ。他プロジェクトでは以下の難度基準と引継ぎ書式を流用し、役割とモデルの利用可能IDを確認し直す。

## モデル選択

| 表示名 | 確認済み設定ID（2026-09-10） | 対象 | 推論の目安 |
| --- | --- | --- | --- |
| GPT-5.6-Luna | `gpt-5.6-luna` | 明確な検索・一覧化、確定済み文言・表示名・限定データ調整 | low〜medium |
| GPT-5.6-Terra | `gpt-5.6-terra` | 方式が決まった通常実装、局所修正、既存構成への追加 | medium |
| GPT-5.6-Sol | `gpt-5.6-sol` | 複数機能、状態遷移、フレーム・タイミング不具合、方式比較、複雑なレビュー | medium〜high |
| GPT-6-Astra | `gpt-6-astra` | 全体設計、対戦基盤、大規模移行、重大な原因不明問題 | medium〜high |

- 品質を満たせる最も低コストなモデルを選ぶ。ファイル数、文字数、1行の変更かどうかだけで選ばない。参考文書中のモデル名は利用可能性の証拠ではない。
- 重要な設計は最初からSol/Astraで判断し、確定後はTerra等に実装を委任する。Astraを統括・実装・確認に常用しない。最高推論設定を常用しない。
- 親と子の既定値はTerra / medium。役割名だけで自動的に上位モデルにはならない。親が作業ごとにモデルと推論を実際の起動機能へ渡す。
- 調査でも不確実性や依存関係が大きければ上位へ。アセット参照、入力・対戦タイミングへの影響がある変更を、機械作業という理由でLunaへ落とさない。
- 進展のない修正が2回続いたら試行と結果をまとめ、必要に応じて1段上位へ。接続、権限、環境不足は先に原因を切り分ける。
- 通常は親＋サブ0〜2体。短い作業の委任、重複調査、全員の一斉起動、完了後の無目的な追加検証を避ける。
- モデル実績、利用量、クレジットは取得できた値だけを報告する。価格比較・削減率はこの表から算出しない。

## 実際の指定と優先順位

正式なカスタムエージェントは `.codex/agents/<role>.toml` に置く。必須キーは `name`、`description`、`developer_instructions`。このプロジェクトでは6ファイルとも `model` と `model_reasoning_effort` を省略する。

子のモデル・推論は各項目について、役割ファイルの固定値 → 明示的なspawn指定 → `[agents]`の既定値 → 親の値、の順に優先される。役割ファイルにモデルを固定するとspawn指定より優先されるため、役割定義にモデルを追加しない。モデルだけがspawnまたは既定値で選択され、推論の明示値・設定値がない場合はそのモデルの既定推論が使われる。曖昧な継承を避け、起動時は両方を指定する。

親の通常設定は、CLIオプション・セッション指定 → 信頼済みプロジェクト設定 → 選択したプロフィール → 個人設定 → その他既定値。管理ポリシーは別途適用される。アプリの既存タスクやモデル選択UIは明示的なセッション設定を保持し得る。ファイル編集だけで現在の親がTerraになったと扱わない。

起動ツールに役割指定欄があれば、登録された役割名と明示的なモデル・推論を渡す。利用中のAPIに役割指定欄がない場合は、該当TOMLの役割指示を読み、委任メッセージへ引継ぎ内容と一緒に渡す。未提供の `agent_type` 等の引数を作らない。

履歴全体のフォークがモデル指定と両立しないAPIでは、必要な履歴のみを渡すか、履歴なし＋具体的な引継ぎを使う。モデル指定不可のAPIでは変更したふりをせず、UIでのモデル選択など対応する操作を案内する。

## 引継ぎ書式

```text
担当役割／実モデルID／推論／選定理由:
目的:
確定仕様・根拠:
対象ファイルと編集可否（他担当との境界）:
判断理由・採用済み方針:
未解決点／再現条件／試したことと結果:
Unity Editor操作担当（必要な場合）:
完了条件・必要な検証:
返却内容: 変更と根拠、検証結果、未検証、調整方法
```

設定と優先順位の根拠：[公式Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)、[公式Config basics](https://learn.chatgpt.com/docs/config-file/config-basic)。モデルID・推論の対応はこの端末のCodex 0.153.4モデルカタログと現在の起動ツールで確認。別環境・将来のバージョンでは再確認する。
